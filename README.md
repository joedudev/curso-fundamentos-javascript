## 📖 About the Course

**Level:** Beginner · **Lessons:** 55 · **Content:** 7 hours · **Practice:** 12 hours

This course covers JavaScript basics: variables, data types, conditional structures, loops, arrays, functions, objects, promises, asynchronous programming, and object-oriented programming through hands-on projects.

## 🧠 What I Learned

- ✅ Variables, primitive & complex data types, and type conversion
- ✅ Comparison and logical operators
- ✅ Conditional structures (`if`, `else`, `switch`)
- ✅ Loops (`for`, `for...of`, `for...in`, `while`, `do...while`)
- ✅ Functions, arrow functions, and lexical scope (`this`)
- ✅ Scope chain and closures
- ✅ Array methods: `map`, `forEach`, `filter`, `reduce`, `find`, `findIndex`, `slice`, spread operator
- ✅ Object-oriented programming: objects, constructor functions, classes, prototypes, and inheritance
- ✅ Synchronous vs. asynchronous programming
- ✅ Promises and `async/await`
- ✅ HTTP fundamentals and the Fetch API (`GET`, `POST`, `DELETE`)
- ✅ DOM manipulation and event delegation
